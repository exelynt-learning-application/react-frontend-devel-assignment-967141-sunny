
## 5. Understanding Git Commands

### git --version

This command checks whether Git is installed and displays the installed version.

### git config --global user.name

This command sets the username that Git associates with commits.

### git config --global user.email

This command sets the email address associated with Git commits.

### git config --global --list

This command displays the global Git configuration settings, including username, email, and other configured values.

### git config --global init.defaultBranch main

This command sets the default branch name to main for newly initialized repositories.

### pwd

This command displays the absolute path of the current working directory.

### ls

This command lists files and directories in the current working directory.

### cd

This command changes the current working directory to another directory.

## 6. Why Git Configuration Is Important

Git configuration is important because it identifies the author of each commit and ensures that repository settings are consistent. Setting the default branch to main also helps maintain a consistent naming convention across new projects.

## 7. Git Workflow

A basic Git workflow consists of the following steps:

1. Create or modify files.
2. Check changes using git status.
3. Stage changes using git add.
4. Commit changes using git commit.
5. Push changes to GitHub using git push.

Example commands:

```bash
git status
git add git-setup-log.md
git commit -m "Complete Git setup documentation"
git push
```

These commands help track, save, and share project changes.
